# Игра "Змейка"

Это простая игра "Змейка", написанная на языке Python с использованием библиотеки `pygame`. Игрок управляет змейкой, которая движется по игровому полю, собирая еду и становясь длиннее. Игра заканчивается, когда змейка сталкивается с границей поля или своим собственным телом.

## Установка

1. Убедитесь, что у вас установлен Python 3.6 или выше.
2. Установите библиотеку `pygame`, если она еще не установлена:
    ```sh
    pip install pygame
    ```

## Запуск игры

1. Скачайте или скопируйте репозиторий.
2. Запустите файл `snake_game.py`:
    ```sh
    python snake_game.py
    ```

## Правила игры

- Используйте клавиши со стрелками для управления змейкой:
  - Левая стрелка: движение влево
  - Правая стрелка: движение вправо
  - Верхняя стрелка: движение вверх
  - Нижняя стрелка: движение вниз
- Собирайте еду (зеленые квадраты), чтобы увеличивать длину змейки.
- Избегайте столкновений с границами игрового поля и собственным телом змейки.

## Структура кода

- `import pygame`, `import time`, `import random`: Импорт необходимых библиотек.
- `our_snake(snake_block, snake_list)`: Функция для отрисовки змейки.
- `message(msg, color)`: Функция для отображения сообщений на экране.
- `gameLoop()`: Основной игровой цикл, который обрабатывает события, обновляет состояние игры и отрисовывает объекты на экране.
